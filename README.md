# 📂 Portafolio de Aseguramiento de Calidad (QA Manual Testing)

¡Hola! Bienvenido a mi repositorio de pruebas manuales. Aquí documento mis prácticas profesionales de diseño y ejecución de estrategias de prueba aplicadas a sistemas de Comercio Electrónico (E-Commerce) y plataformas financieras (Banca en Línea).

## 🛠️ Tecnologías y Herramientas Utilizadas
*   **Gestión y Diseño de Pruebas:** Jira Software / Azure DevOps

*   **Metodologías Ágiles:** Scrum (Framework para gestión de HU y Criterios de Aceptación)
*   **Formatos Estándar:** Documentación Maestra combinando Test Scenarios y Test Cases en tablas GFM (GitHub Flavored Markdown).

## 🗂️ Estructura del Repositorio
*   `escenarios-y-casos/`: Carpeta unificada por módulos funcionales del negocio.
    *   [login_modulo.md](./escenarios-y-casos/login_modulo.md): Estrategia de pruebas completa para el control de accesos (6 Escenarios de Alto Nivel y 6 Casos de Prueba con data técnica, flujos alternativos, negativos y de seguridad).

## 🧠 Habilidades Técnicas Demostradas en este Proyecto
1.  **Análisis de Requisitos:** Traducción de Historias de Usuario (*User Stories*) en Escenarios Macros de Prueba (*Test Scenarios*).
2.  **Diseño de Casos de Prueba:** Cobertura total utilizando técnicas de Caja Negra, flujos funcionales positivos, manejo seguro de errores (Flujos Negativos) y validación de reglas de negocio en la interfaz.
3.  **Enfoque de Seguridad:** Pruebas de controles de bloqueo por intentos fallidos y formatos estrictos de campos obligatorios.
